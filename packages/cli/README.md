# @bobnoddle/quark-create-app CLI

Scaffold a new Quark project.

Canonical setup instructions (Windows + macOS/Linux):

- [../../README.md](../../README.md)

Minimal usage:

```bash
npx @bobnoddle/quark-create-app@latest my-awesome-app
```

Maintainers (this repo):

```bash
pnpm new my-awesome-app
```
- Updating Quark packages with `quark-update`
- Environment configuration
- Troubleshooting common issues
